## What Is This

An AI-powered murder mystery where every suspect is a live agent — not a scripted NPC. Players interrogate three AI suspects per case using real questions. Every response is generated by **Groq Llama 3 (70B)** through a 9-stage pipeline with RAG-grounded retrieval, emotional state escalation, and real-time WebSocket streaming. No pre-written dialogue. No two interrogations are the same.

Directly addresses **SIH Problem Statement #25198** — AI-powered interrogation simulation for structured investigative training.

## Architecture

**The 9-Stage Message Pipeline** — every message runs through this before a word is generated:

```
User message → WebSocket → FastAPI
  1. State Machine     [Python]     CALM → DEFENSIVE → BREAKING (keyword-triggered)
  2. Intent Classify   [Groq LLM]   ALIBI / MOTIVE / TIMELINE / GENERAL
  3. RAG Retrieve      [ChromaDB]   Top-3 semantically relevant case document chunks
  4. Prompt Assembly   [Python]     State + Intent + Context + History + Message
  5. Stream Response   [Groq LLM]   Token-by-token via WebSocket → Frontend
  6. Rule Engine       [Python]     9 keyword rules per case — instant clue detection
  7. AI Clue Detect    [Groq LLM]   Fires only if no rule matched (~30% of exchanges)
  8. Suspicion Score   [Groq LLM]   0–100 linguistic deceptiveness rating
  9. Meta JSON         [Python]     clue + suspicion_score + emotional_state → client
```

**4 Groq LLM calls per message. 0 ML models. 100% GenAI + Agentic AI.**

## Key Design Decisions

| Decision | Why |
|----------|-----|
| **Groq Llama 3 70B** | LPU inference — lowest latency of any free-tier provider. Critical for real-time streaming feel. |
| **Emotional state machine in Python** | State transitions are deterministic keyword rules, not LLM decisions — reliable and repeatable. |
| **RAG with ChromaDB** | Suspects retrieve from real case documents (records, blueprints, witness statements) — not hallucination. |
| **Hybrid clue detection** | Python rules catch 74% of clues instantly. Groq fallback handles the rest. No quota waste. |
| **WebSocket over HTTP** | Streaming starts at ~0.8s. Standard POST would mean 3–5s wait before any response appears. |
| **One file per agent / per prompt** | Strict separation of content and logic. Characters can be refined without touching pipeline code. |

## Setup

```bash
# Backend
cd backend && python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
echo "GROQ_API_KEY=your_key" > .env
python rag/setup_db.py          # one-time ChromaDB ingestion
uvicorn main:app --reload --port 8000

# Frontend
cd frontend && npm install
echo "VITE_API_URL=http://localhost:8000" > .env
npm run dev
```

Verify backend: `http://localhost:8000/health` → `{"status":"ok"}`

**Render (backend):** Root `backend/` · Start: `uvicorn main:app --host 0.0.0.0 --port $PORT` · Env: `GROQ_API_KEY`
